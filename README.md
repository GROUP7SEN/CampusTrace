# 📍 CampusTrace - OAU Lost & Found Portal

> **Live Application**: [https://campustrace.samkiel.dev](https://campustrace.samkiel.dev)

CampusTrace is a modern, student-centric Lost & Found web platform engineered specifically for Obafemi Awolowo University (OAU), Ile-Ife. Designed to eliminate fragmented social media lost item notices, CampusTrace provides a unified real-time dashboard for publishing, discovering, delegating, and claiming lost belongings on campus.

## ⚡ Key Features & Capabilities

- 📢 **Instant Publication**: Fast reporting of missing or found belongings with automated image optimization.
- 💬 **Direct WhatsApp & Email Messaging**: Automated, pre-formatted direct chat links between finder and owner.
- 🛡️ **Administrative Security Delegation**: Assign reports to university bodies (OAU Security Unit, DSA, Library, Department Secretariats).
- 🔍 **Real-Time Search & Category Filters**: Multi-criteria keyword, category, and missing/found status filtering.
- 🔒 **User Account Moderation**: Full administrator controls with user suspension enforcement and audit management.
- 📱 **Mobile-First Responsive Interface**: Tailored card views, image lightboxes, and dark-mode aesthetic.
